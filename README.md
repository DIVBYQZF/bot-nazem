# 🎫 بوت تذاكر ديسكورد المتطور (Discord Ticket Bot)

بوت تذاكر ديسكورد احترافي وشامل، مبرمج بلغة **JavaScript (Node.js)** باستخدام أحدث إصدار من مكتبة **Discord.js (v14)** مع دعم واجهة عربية متكاملة وسجلات تفاعلية بتنسيق HTML.

---

## ✨ الأقسام المعتمدة
1. ❓ **استفسار:** للمساعدة والإجابة عن أي استفسار أو سؤال.
2. 🚨 **شكوى على عضو:** لتقديم بلاغ أو شكوى رسمية ضد عضو أو إداري.
3. 💼 **تقديم على الاداره:** للتقديم على رتبة في طاقم إدارة السيرفر.

## 🌐 موقع لوحة التحكم الاحترافي (Web Dashboard)
يأتي البوت مزوداً بلوحة تحكم ويب متكاملة تعمل على المتصفح:
- **الرابط:** [http://localhost:3000](http://localhost:3000)
- **المميزات:**
  - 📊 متابعة حالة البوت الحية (Ping، وقت التشغيل، التذاكر المفتوحة، إجمالي التذاكر).
  - 🎫 تخصيص كل قسم من أقسام التذاكر واختيار **رتبة إدارية مخصصة لكل قسم على حدة** (بدون الحاجة لنسخ الآيديات، تظهر الرتب في قائمة منسدلة تلقائياً).
  - 🚀 إرسال لوحة التذاكر إلى أي روم بالسيرفر بضغطة زر واحدة من الداشبورد.
  - 🔔 فحص وتجربة نظام اللوقات مباشرة.
  - 🔢 تخصيص نظام تسمية التذاكر بالأرقام وتعديل عداد التذاكر.
  - 🎨 تخصيص كامل لألوان الـ Embeds.

---

## 🔢 نظام التسمية بالأرقام (بدون أسماء الأعضاء)
تم تحويل تسمية قنوات التذاكر بالكامل إلى **أرقام متسلسلة** لمنع ظهور أسماء الأعضاء في القنوات:
- `شكوى-0001` أو `استفسار-0001` (بادئة القسم + الرقم المتسلسل).
- أو `ticket-0001` أو `0001` (أرقام فقط).
- يمكن تغيير طريقة التسمية أو تصفير العداد في أي وقت من لوحة التحكم الويب.

---

## 🔒 نظام السجلات والنسخ (خاص بالإدارة فقط)
- **نسخ سجل التذكرة (Transcript):** مقتصر بالكامل على الإدارة وفريق الدعم. لا يتم إرسال المحادثة في الخاص للأعضاء العاديين.
- **لوقات متكاملة (Logs):** تسجيل فوري لجميع العمليات في روم الإدارة المخصص:
  - 🎫 لوق فتح التذكرة مع تفاصيل العضو والقسم والروم.
  - 🔒 لوق إغلاق التذكرة مع ملف الـ HTML الكامل مرفقاً.
  - 🙋‍♂️ لوق استلام التذكرة من قبل الإداري.
  - ⚠️ لوق إلغاء الاستلام.
  - ➕ لوق إضافة عضو للتذكرة.
  - ➖ لوق إزالة عضو من التذكرة.
  - 📑 لوق طلب نسخة من المحادثة.

---

## 🎮 أوامر السلاش (Slash Commands)
- `/ticket-setup [channel]`: إرسال لوحة التذاكر المحدثة في الروم المحددة.
- `/set-logs [channel]`: تعيين روم اللوقات وسجلات الإدارة بضغطة زر.
- `/set-role [role]`: تعيين رتبة الدعم الفني والإدارة المسؤولة عن التذاكر.
- `/add @user`: إضافة عضو للتذكرة لمشاركته النقاش.
- `/remove @user`: إزالة عضو من التذكرة.
- `/claim`: استلام التذكرة أو إلغاء استلامها.
- `/close`: طلب إغلاق التذكرة الحالية مع حفظ نسختها للإدارة.

## 🚀 طريقة التثبيت والتشغيل خطوة بخطوة

### 1. إعداد تطبيق البوت في Discord Developer Portal
1. ادخل إلى [Discord Developer Portal](https://discord.com/developers/applications).
2. اضغط على **New Application** وأدخل اسم البوت.
3. من القائمة الجانبية ادخل إلى قسم **Bot**:
   - اضغط على **Reset Token** لنسخ توكن البوت (`DISCORD_TOKEN`).
   - فعّل خيارات **Privileged Gateway Intents**:
     - ✅ **Presence Intent**
     - ✅ **Server Members Intent**
     - ✅ **Message Content Intent**
   - اضغط **Save Changes**.
4. من قسم **OAuth2** انسخ **Client ID**.
5. ادعُ البوت إلى سيرفرك برابط دعوة يحتوي على صلاحيات **Administrator** أو الصلاحيات الضرورية (إدارة القنوات، إدارة الرسائل، إنشاء الرولات).

---

### 2. إعداد المتغيرات (`.env`)
قم بفتح ملف `.env` واملأ البيانات كالتالي:

```env
DISCORD_TOKEN=التوكن_الخاص_بالبوت_هنا
CLIENT_ID=معرف_البوت_هنا
GUILD_ID=معرف_سيرفرك_هنا
```
> **ملاحظة:** وضع `GUILD_ID` يجعل أوامر السلاش تظهر فوراً في سيرفرك بدون انتظار وقت التحديث العالمي لديسكورد.

---

### 3. تخصيص الإعدادات (`config.json`)
افتح ملف `config.json` لتحديد الرتب والرومات:
- `"supportRoleId"`: أيدي رتبة الدعم الفني التي تملك صلاحية رؤية التذاكر والرد عليها والتحكم بها.
- `"ticketCategoryId"`: أيدي التصنيف (Category) الذي ستُنشأ التذاكر تحته (إذا تركته فارغاً، سيقوم البوت بإنشاء تصنيف تلقائياً باسم `🎫・التذاكر`).
- `"logsChannelId"`: أيدي روم السجلات الذي سيُرسل إليه إشعارات فتح وإغلاق التذاكر مع ملفات الـ Transcript.
- `"maxTicketsPerUser"`: أقصى عدد للتذاكر المفتوحة لكل شخص (الافتراضي: 1).

---

### 4. تسجيل أوامر السلاش (Deploy)
لتسجيل الأوامر في سيرفرك، افتح موجه الأوامر (Terminal) واكتب:

```bash
npm run deploy
```

ستظهر لك رسالة تأكيد تفيد بأنه تم تسجيل الأوامر بنجاح.

---

### 5. تشغيل البوت
لتشغيل البوت:

```bash
npm start
```

---

### 6. إرسال لوحة التذاكر في السيرفر
1. في السيرفر، اكتب الأمر:
   ```text
   /ticket-setup
   ```
   (يمكنك اختيار الروم التي ترغب بإرسال اللوحة فيها عبر خيار `channel`).
2. ستظهر لوحة الدعم الفني مع قائمة منسدلة، بمجرد أن يختار العضو قسماً، سيتم إنشاء قناة خاصة له فوراً!
